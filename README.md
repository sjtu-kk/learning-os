# Learning OS

A responsibility-first personal learning operating system for turning fragmented inputs into reusable capability.

This repository contains the public skeleton and control plane only. Personal Areas, Projects, Resources, Notes, Reviews, and Archive content are intentionally kept local.

## Structure

```text
system/       Rules, protocols, templates, and execution prompts
resources/    Processed external resources; clippers/ and raw/ are intake
assets/       Physical attachments
inbox/        Personal notes whose owner is not yet known
areas/        Long-lived domains
projects/     Bounded activities with goals and exit conditions
reviews/      Central daily and monthly reviews
archive/      Retained historical material
```

Start with `AGENTS.md`, then use `system/index.md` to load only the protocol required by the current action.

## Core Model

Learning turns real demand into independent performance through exploration, practice, feedback, targeted supplementation, re-practice, transfer, and review. The complete learning behavior model and capture contract live in `system/protocols/learning-behavior.md`.

The system uses stable responsibilities for physical ownership. Lifecycle is represented by status, links, reviews, and archival decisions rather than by duplicating every topic into lifecycle folders.
