# Metadata, Tags, and Wikilinks

Use frontmatter with `type`, `status`, `created`, `updated`, `areas`, `projects`, `questions`, and `tags` where applicable. Reuse existing tags; keep 3-5 meaningful tags. Tags are filters, not owners. Link owners and related notes with `[[exact note title]]`; README indexes must use real wikilinks or verifiable Dataview queries. Verify targets after moves and avoid duplicate active truths.
