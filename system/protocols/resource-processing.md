# Resource Processing Protocol

Level 1: preserve original content and source, add concise summary, Properties, 3-5 reusable tags, links to existing Areas/Projects/Questions, and status; then move the single file from intake to `resources/` root. Level 2 is added only when used for learning, a decision, or review: record key facts, author claims, evidence, applicability, conflicts, and personal impact. Unknown associations remain unassigned. Never create an Area/Project/Tag to force a link.

Minimum Properties: `type`, `source`, `source_url`, `captured_at`, `status`, `areas`, `projects`, `questions`, `tags`. Use YAML arrays for multi-value fields and valid wikilinks in body text.
